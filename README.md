# MediCare-360 — Hospital Management Platform

MediCare360 is a comprehensive, multi-role hospital management web platform engineered for modern healthcare institutions. It provides role-tailored dashboards, real-time patient monitoring, appointment scheduling, electronic health records (EHR), pharmacy inventory control, billing workflows, and unified administration.

---



---

## 👥 Role-Based Portals

1. **Administrator:** System configuration, user accounts, doctor management, staff assignment, clinical departments, audit logs, and reports.
2. **Doctor:** Patient consultations, diagnosis logging, prescription issuance, appointment schedule management.
3. **Nurse:** Inpatient vitals tracking, assigned patient monitoring, nursing task execution.
4. **Receptionist:** Patient registration, appointment booking, doctor availability tracking, intake billing.
5. **Pharmacist:** Drug inventory management, low stock alerts, electronic prescription dispensing.
6. **Patient:** Appointment booking, medical records, electronic prescriptions, bills and payments.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS + Vanilla CSS Tokens
- **Icons:** Lucide React
- **Routing:** React Router DOM
